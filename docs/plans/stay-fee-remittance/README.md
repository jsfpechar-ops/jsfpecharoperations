# Stay-fee remittance — plans and design material

Everything here is **planning material for the host-only stay-fee remittance
tool** (monthly *Měsíční hlášení* PDF, §3g CSV, QR Platba for the council).

- `PLAN_STAY_FEE_REMITTANCE.md` — the implementation plan.
- `stay-fee-document*.html` / `*.jpg` — what the monthly report looks like
  (Praha 3 and Brno variants).
- `stay-fees-list*` and `stay-fees-detail*` — the host's fee screens.
- `qr-platba.png`, `ubyhost-mark.png` — assets the mockups reference.

**Plans only.** Nothing in this folder is shipped to the app — no code, no
templates, no routes. The feature is not implemented; `PLAN_STAY_FEE_REMITTANCE.md`
is PLANNING status and needs owner review before any code is written.
