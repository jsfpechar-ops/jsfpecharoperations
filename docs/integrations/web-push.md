# Integration: Web Push (browser push notifications)

- Own ES256 VAPID signing in `App/app/webpush.py`; HTTP POST to the browser's push endpoint from each subscription (`requests`, 10 s, no redirects; subagent report).
- VAPID key generated by the app and stored encrypted (`App/app/push.py`).
- Job: `push` every 1 min (`App/app/scheduler.py`). Toggle: `UBYHOST_WEB_PUSH` (default on; `App/app/config.py:189`).
- Specs: RFC 8030 https://datatracker.ietf.org/doc/rfc8030/ and RFC 8292 https://datatracker.ietf.org/doc/rfc8292/ (see [REFERENCES](REFERENCES.md)).
