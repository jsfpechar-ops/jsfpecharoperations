## 1. What was served, and how

```

Server: `/var/tmp/ubyhost-web-parity` on `127.0.0.1:8099` with the env above. Sessions were minted the way the audit does it, but for the Go server, using the repo's own dev helper — **no production cookies, no real credentials**:

```

(`UID` is read-only in zsh, hence `env UID=`.) `/login/2fa` is POST-only (GET always 303), so a pending token was minted with `App/.venv/bin/python -c "from app import auth; print(auth.issue_two_factor_pending(163))"` and the page was rendered by POSTing `_csrf` to `/login/2fa`. `/account/accept` was additionally tried against 8098 as described.

Capture was done with Playwright directly (`/tmp/ux_capture.py`, standalone, viewport 1000 px high, `full_page=True`), not with `App/scripts/go_page_parity_screenshots.py` — that script is broken and is recorded, not patched, in §6.
