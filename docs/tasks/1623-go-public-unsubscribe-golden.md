## 1. Objective

Add the Python golden script that drives `GET` and `POST /mail/unsubscribe/{token}` with the real FastAPI app in 21 cases, and writes the string catalog (en, cs, vi), real signed tokens, the expected HTML, headers, cookies and the rows left in the database for each case, plus a test that fails when they are stale. Brief 1624 ports the two routes on top of these files. This brief changes no Go and no behaviour.

## 2. Context

Rules (AGENTS.md): 1 filing is not touched; 2 privacy: no new outbound request, no new cookie; the script only reads the app; 3 made-up data only (`tip@example.test`, accounts `host` and `opted`, a test-only secret); 4 no new dependency; 8 never push to `main`; 11 Go first (port plumbing: golden script and parity test).

**PR text (hard rule 2):** no new outbound request and no new personal-data field.

How it works (the orchestrator wrote and ran the script; you copy it):

- It imports `scripts/public_legal_golden.py` (brief 1270): same throwaway SQLite database, same `config` patching, same `normalize()`. Before each case it empties `audit`, `mail_suppression`, `rate_limit_event`, `user_account` and inserts account 1 (`host`, opted in) and account 2 (`opted`, already opted out); a case may first record 30 rate-limit events (the limit is 30 per hour).
- Tokens are the real `lifecycle_mail.unsubscribe_token` values under the golden secret: `host` (account 1 with an address hash), `host_no_address`, `opted` (account 2), `unknown_user` (account 99), `forged` (bad signature). They are deterministic.
- The page extends `auth_base.html`, which prints a CSRF token twice and sets the `ubyhost_csrf` cookie with a random nonce. The script blanks both token values in the HTML and the cookie value; the Go test does the same. The cases pin the env banner (`UBYHOST_UBYPORT_ENV` mock or production, `UBYHOST_DEPLOYMENT` production), the `?notice=` message, the language rules (`?lang=`, cookie, Vietnamese stays Vietnamese here) and the cookies Python sets.
- Per case it also records the rows left behind: the accounts' opt-out flag, `mail_suppression`, `audit` (`actor`, `action`, `detail`, owner and actor ids) and the count of `rate_limit_event` rows. This is the "same row written" proof for brief 1624.
- Catalog `go/internal/web/public/catalog_unsub.json`: `strings` for the page, the auth shell and the env banner in `en`, `cs`, `vi`, and the 14 px check icon. Never edit it by hand.
