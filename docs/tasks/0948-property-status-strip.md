## 1. Objective
Owner: the property page is slow because the host opens each section one by one to see what is wrong. Put a compact six-card status strip (Calendars, Guest link, Police reporting, Business details, Stay fee, Door code) at the top of `/apartments/<id>`. Each card: status dot, title, one status line (the problem text when there is one). Tapping a card scrolls to and opens its section. Also move the "Copy settings from another property" button into the header action row (step 6), and fix the guest link card so its left and right edges equal the content grid below it.
