## 1. Objective

The Opus review of 1222 found that a stored date shorter than 10 characters makes `s[:10]` panic and takes down the whole Go process. It also found that the two new golden scripts would seed and bill whatever database `UBYHOST_DB` or `UBYHOST_DATABASE_URL` already points to. This brief fixes both.

## 2. Context

Non-test Go slices to replace (exact lines):
- `go/internal/billingjob/run.go`: `	from, to := acc.PeriodStart[:10], acc.PeriodEnd[:10]`
- `go/internal/billingjob/apartments.go`: `		to = acc.PeriodEnd[:10]`
- `go/internal/billingjob/trial.go`: `			ok, err := r.billingTrialMail(ctx, t.owner, left, t.ends[:10])`
- `go/internal/billingjob/dunning.go`: `		floorDiv(inv.totalHaler, 100), fmtDate(inv.due[:10]), fmtDate(today.Format(isoDate)))`
`go/internal/billingjob/account.go` has `func parseDate(value string) (time.Time, error)`, which truncates to 10 and errors on bad dates.
Golden scripts (at base commit `47262ae`), each has these two lines in its `__main__` block:

`App/scripts/billing_invoice_golden.py`:
```python

```

```python

```

## 4. Steps

1. In account.go, right after the `parseDate` function, add:
```go
// day10 is Python's value[:10] without the panic on a short string.
func day10(s string) string {
	if len(s) > 10 {
		return s[:10]
	}
	return s
}
```
2. run.go: replace the `from, to := ...` line with:
```go
	if _, err := parseDate(acc.PeriodEnd); err != nil {
		return false, err
	}
	from, to := day10(acc.PeriodStart), day10(acc.PeriodEnd)
```
3. apartments.go: `acc.PeriodEnd[:10]` -> `day10(acc.PeriodEnd)`. trial.go: `t.ends[:10]` -> `day10(t.ends)`. dunning.go: `inv.due[:10]` -> `day10(inv.due)`.
4. Then `grep -n '\[:10\]' go/internal/billingjob/*.go | grep -v _test.go`: only the line inside `day10` and the one inside `parseDate` may remain.
5. unit_test.go: append
```go
func TestDay10(t *testing.T) {
	for in, want := range map[string]string{"": "", "2026-1-1": "2026-1-1", "2026-11-13T06:00:00": "2026-11-13"} {
		if got := day10(in); got != want {
			t.Errorf("day10(%q) = %q, want %q", in, got, want)
		}
	}
}
```
6. In `App/scripts/billing_invoice_golden.py`, replace the two `setdefault` lines quoted in §2 with:
```python
    os.environ["UBYHOST_DATA_DIR"] = str(tmp)
    os.environ["UBYHOST_DB"] = str(tmp / "billing_invoice_golden.sqlite3")
    os.environ.pop("UBYHOST_DATABASE_URL", None)
```
In `App/scripts/billing_run_golden.py`, replace its two `setdefault` lines with:
```python
    os.environ["UBYHOST_DATA_DIR"] = str(tmp)
    os.environ["UBYHOST_DB"] = str(tmp / "billing_run_golden.sqlite3")
    os.environ.pop("UBYHOST_DATABASE_URL", None)
```
7. Run §6, write the report, commit `1222-fix-1`.
