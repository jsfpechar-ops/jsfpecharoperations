## 1. Objective

Owner decision 2026-11-22 (D4): on the guide import section of `GET /apartments/{id}/guide` a host can paste a public page link (Notion public page first). The existing Apify fetcher reads the page, `FilterCodes` (2035) removes access codes before the model sees the text and again on the model output, the model drafts guide cards in state `check` (the host approves each one; nothing is auto-published), and the host sees "We left out N codes. Add them under Entry codes." (count only).

```sql

ALTER TABLE guide_import ADD CONSTRAINT guide_import_source_check CHECK (source IN ('booking', 'airbnb', 'url'));
```
