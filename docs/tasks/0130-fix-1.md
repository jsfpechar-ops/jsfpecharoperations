## 1. Objective

CI `test` fails after 0130 and 0129 for two reasons:
1. Three tests still look for the old shell markup. The v2 sidebar (`_shell_sidebar.html`) renders the badge as `class="env-badge ui-env prod"` and the logo mark lives in `_shell_sidebar.html`, not in `base.html`. The behaviour is right; the tests must read the new markup.
2. `tests/test_design_page_template.py` registers `/__design_sample_<kind>` routes on the real `app` and deletes the sample templates in teardown, but never removes the routes. `tests/test_privacy_first.py` later crawls every app route and gets `TemplateNotFound '_sample_detail.html'`. Remove the routes in teardown.

Change tests only. No template, CSS or app code changes.
