Behaviour to copy exactly:
- `lang` is normalised by `host_i18n.normalise_language` (Go: `mailnotify.HostLanguage`, `mailnotify/i18n.go:84`); all labels come from the HOST catalogue keys `mail.guest_details_host.*` (`App/app/host_i18n.py` ~11262 onward: `gone`, `unnamed`, `nationality_label`, `state_label`, `state.pending|sent|error|blocked|not_required`, `birth_label`, `address_label`, `doc_type_label`, `doc_number_label`) and `guest.doc_type.<key>` for known document types (`validation.DOC_TYPES`, `App/app/validation.py:165`; aliases `p` gives `pas`, `id` gives `op`; unknown non-empty raw code is shown as the raw code).
- stay missing, or no active guests: `gone` text; HTML wraps it in `_block_paragraph`.
- rows always: nationality (label from the code via the language list, "–" when empty; unknown code shows the upper-cased code) and state (translated when in the five keys, else the raw state; empty state means `pending`). Only when `full`: birth date (`fmt_date`), address (street, city, country each stripped, non-empty parts joined with ", "), document type label, masked document number.
- text: per guest `name` newline then lines `"  {label}: {value}"`; guests joined by a blank line. HTML: per guest `BlockPanel(name, rows)` concatenated.
- `owner_user_id` comes from the stay's apartment (`reservation JOIN apartment`).
