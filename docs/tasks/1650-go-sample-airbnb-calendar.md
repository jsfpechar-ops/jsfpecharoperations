Port `sample_calendar.sample_airbnb_ics` (`App/app/sample_calendar.py` 11-50) as `ical.SampleAirbnbICS(today time.Time) string`. Brief 1597 (`POST /demo`) needs it for the demo property's sample feed, and the route `GET /sample-airbnb.ics` (`main.py`, still Python) can serve it later.

## 2. Context

Rules (AGENTS.md): 2 no personal data (made-up phone digits of a sample calendar), no outbound request. 3 nothing secret. 4 no dependency (standard library). 11 Go first: this is port plumbing for a Go brief.

Python builds ten events around "today" (offsets -8, -1, 0, 1, 3, 5, 7, 12, 45 and 20 days, 1 to 4 nights), joins the lines with CRLF and ends with CRLF. `today` is `deadlines.local_now().date()`, the Czech civil date; the Go function takes the date from its caller (callers pass `deadlines.LocalNow(now)`), so the function itself has no clock and no time zone.
