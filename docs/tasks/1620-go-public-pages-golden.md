Add the Python golden script that renders `GET /jak-to-funguje`, `GET /cenik` and `GET /pruvodce/{slug}` with the real FastAPI app in 29 cases, and writes the string catalog (en, cs), the guide texts, the price list and two icons for Go, plus a test that fails when they are stale. How it works (the orchestrator wrote and ran every file; you copy them, you do not write code):

- The script imports `scripts/public_legal_golden.py` (brief 1270) and reuses its case runner: same throwaway SQLite database, same `config` patching from the case's env, same `normalize()` (ASCII whitespace runs to one space, `> <` to `><`, trimmed). It adds one patch of its own: `og:image` prints the template global `public_base_url`, which `templating.py` fixes at import time, so the script patches that global with the case's base URL.
- Catalog `go/internal/web/public/catalog_pages.json`: `strings` (every key under `product.`, `pricing.`, `landing.`, `privacy_first.`, `guide.` plus the header and footer keys, in `en` and `cs`), `guides` (`GUIDE_TRANSLATIONS`: texts and the dictionary order of the slugs), `rates` (`legal.PUBLIC_RATES`) and the two 14 px icons the pages print (`check`, `external-link`). Never edit it by hand.
- Cases (`testdata/pages/cases.json` and one `.html` each): product, pricing in CS, EN, PostHog on, cookie `en`, cookie `vi`, and `?lang=cs` over cookie `en`; product with an http base URL; pricing with sign-up on (plain, cookie `vi`, with utm labels, a plan choice and a bad `click` value, and with PostHog); both guides in CS, EN, PostHog on and cookie `en`; a guide with an http base URL; an unknown guide slug in CS and EN (404 JSON). `?lang=vi` on a guide is not a case: Python raises `KeyError` there and answers 500 (`GUIDE_TRANSLATIONS` has no `vi`); brief 1621 serves English and says so.
- PostHog: Python prints the tag on these three pages only when `POSTHOG_PROJECT_API_KEY` is set (`analytics.PUBLIC_ANALYTICS_TEMPLATES` names `product.html`, `pricing.html` and `public_guide.html`); the `*-posthog` cases pin exactly that, the others pin its absence.
