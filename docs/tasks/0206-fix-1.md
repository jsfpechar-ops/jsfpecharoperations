## 1. Objective

On wide screens the "On" badge sits beside the alerts text but "Send a test" and "Turn off" drop to a separate row with a divider, which reads as a second setting. Put the badge and both buttons together on the right of the alerts row, and drop the stray top border above the first Phone app row.

## 2. Context

`App/app/templates/settings.html`, verbatim (inside `id="settings-alerts"`):

```html
          <button class="ui-btn ui-btn-secondary ui-btn-compact" type="button" data-push-on hidden>{{ t('push.on') }}</button>
          <span class="ui-badge ui-badge-done" data-tone="green" data-push-state-on hidden>{{ t('push.state_on') }}</span>
        </div>
        <div class="ui-form-actions" data-push-controls hidden>
          <button class="ui-btn ui-btn-secondary ui-btn-compact" type="button" data-push-test>{{ t('push.test') }}</button>
          <button class="ui-btn ui-btn-secondary ui-btn-compact" type="button" data-push-off>{{ t('push.off') }}</button>
        </div>
```

`App/app/static/host.css` line, verbatim:

```css
.settings-groups .settings-action-row .btn { white-space: normal; }
```

`[hidden] { display: none !important; }` in app.css keeps hidden spans hidden even with a `display` rule. `pwa.js` toggles `[data-push-controls]` and `[data-push-state-on]` by the `hidden` attribute; it does not care where they sit. At 720 px and below, `.settings-action-row` stacks (column).
