## 1. Objective
The host cleaning page (`/cleaning`) shows its cleanings as tables, like the approved computer mockup (`ubyhost-redesign-v2.html`, view "clean"): a "Today" table, a "This week" table (the next 6 days) and a "Later" table (the rest of the loaded range, shown only when it has rows). Columns: Property, Time (Today) or Day (the other two), Next arrival, Status. The cleaner's shared view (`/cleaning/shared/...`) keeps its cards unchanged.

## 4. Steps
1. **Sections in Python.** In `routes/cleaning.py` add `_sections(cleanings, today)` returning a list of `(key, items)` for `today` (date == today), `week` (today < date <= today + 6 days) and `later` (everything else, including past dates in the range), keeping the input order; drop sections with no items except `today`. In `_payload()`, when `read_only` is false, render `_cleaning_table.html` into `listHtml` with `sections=_sections(payload["cleanings"], cleaning.today())` added to the context; when true, keep `_cleaning_list.html` exactly as now. In `index()` pass the same `sections` to the page. Commit `0540 step 1`.
2. **Table template** `_cleaning_table.html`, one block per section: `<section class="cleaning-section" aria-labelledby="cleaning-section-{{ key }}"><h2 id="cleaning-section-{{ key }}">{{ ct('section_' ~ key) }}</h2>`, then either `<p class="cleaning-empty">{{ ct('today_empty') }}</p>` (only `today` can be empty) or a `ui-table-wrap` table with columns Property (`ct('col_property')`), Time/Day (`ct('col_time')` for today, `ct('col_day')` otherwise), Next arrival (`ct('arrival')`), Status (`ct('col_status')`). Each row: `<tr class="ui-row clickable-row" id="cleaning-{{ item.eventId }}" data-href="/cleaning/events/{{ item.eventId }}/edit" tabindex="0" role="link">`; first cell is a link to the same URL holding the property name (`data-card="primary"`); time cell (`data-card="secondary"`) prints `startTime–endTime` when both are set, else `checkoutTime–checkinTime` when both are set, else `ct('time_missing')` (use an en dash, not an em dash); day cell prints `cleaning_date(item.date)`; arrival cell (`data-card="meta"`) as the card's "arrival" line does today (`cleaning_date(nextArrival) · checkinTime` or `ct('no_arrival')`); status cell (`data-card="badge"`): `ui_badge('action', ct('status_conflict'))` if `conflict`, else `ui_badge('attention', ct('status_hours'))` if `timingUnavailable`, else `ui_badge('neutral', ct('status_scheduled'))`. Import the macros at the top with `{% from "_ui.html" import ui_badge %}{% from "_ui_layout.html" import ui_table_begin, ui_table_end %}` (check `dashboard.html` for the exact import lines). Commit `0540 step 2`.
