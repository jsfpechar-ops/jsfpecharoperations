Promised API (other threads build on it; never rename):

```go
type Env struct { Pool *pgxpool.Pool; Getenv func(string) string; Now time.Time }
type Page struct { Title, Nav, BodyKind string; V2, HideNav bool; HowKey, BackURL string; Status int
                   /* added: */ AdminWorkspace bool; Lang, MetaDescription, NavBadge string; NavActionCount int }
type Templates struct{ /* parsed shell + page files + page catalog; clone per request */ }
func Parse(cat hostweb.Catalog, fsys fs.FS, patterns ...string) (*Templates, error)
func MustParse(cat hostweb.Catalog, fsys fs.FS, patterns ...string) *Templates
func Render(w http.ResponseWriter, r *http.Request, env Env, host *session.Host, p Page, tpl *Templates, name string, data any) error
```

- Page file: `{{define "<name>"}}` is the host_page `body` block; optional slots `<name>.title` (h1, default Page.Title), `.meta`, `.primary`, `.secondary`, `.tabs`, `.toolbar`, `.head`, `.back_label`.
- Funcs: `t "key" ["param" v ...]` (page catalog, then layout catalog, then the key), `tp "key" n`, `lang`, `csrf`, `icon "name" size`, `kv`, `safe`, `datetime_local`, `describe_time_left` and the macros under their Jinja snake_case names (positional args, then an optional trailing `kv` map for keywords; `"caller"` stands in for a Jinja call block). Macros escape every argument; a `| safe` argument is raw only when passed as `template.HTML` (use `safe`).
- Shell reads: one SQL (`shellSQL` in layout.go: workspace display_name, deletion_due_at, non-archived property count). CSRF token and `ubyhost_csrf` cookie as `security.csrf_token`/`attach_csrf_cookie`; `ubyhost_lang` cookie on `?lang=` as `templating.render`/`host_i18n.remember_language`.
- `App/scripts/go_host_i18n.py` globbed `go/internal/*/i18n_keys.txt` only, so it did not find the nested `hostweb/layout/`. The glob becomes `**/i18n_keys.txt` (only change to that script). Nothing in `go/internal/hostweb/*.go` changes.
- Golden: `App/scripts/go_layout_golden.py` renders a test page (three cases: legacy/en with toasts and deletion banner; v2/cs impersonating with undo toast and back link; no-nav/vi) through the real `templating.render` with no DB, writing `testdata/*.html` + `golden_cases.json`. `TestGoldenMatchesPython` renders `testdata/golden_page.html` with the same inputs and compares after `normalise` (`&#43;`→`+`, whitespace runs → one space, the space after `>` and before `<` dropped). `App/tests/test_go_layout_golden.py` runs the script with `--check` in a subprocess.
