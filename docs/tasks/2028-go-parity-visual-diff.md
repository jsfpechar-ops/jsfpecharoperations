## 1. Objective

Make `App/scripts/go_page_parity_screenshots.py` able to compare a signed-in page, then
fix what it shows: the guest form's check-in rail and the landing page's receipt check
mark render differently in Go than in Python even though the audit's text rows pass.

## 2. Context

The tool takes one cookie for both stacks. Python and Go sign their own sessions
(`auth.issue_session` vs `cmd/e2e-issue-session`), so a single value authenticates one
side only and the other renders anonymous. `guest/base.html` has
`<div class="g-wrap {% block wrap_class %}{% endblock %}">`, and only `guest/form.html`
fills that block with `g-checkin-page`; the CSS grid that puts the stay card and the
check-in steps beside the form hangs off that class. `templates/_icons.html` renders
`icon(name, size)` with `width/height = size` and `stroke-width="2 if size <= 16 else 1.75"`,
while `catalog_pages.json` carried only the 14 px art.
