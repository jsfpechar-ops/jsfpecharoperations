## 1. Objective
Plan v4 step 15 (G3), first job. The Go service gets a job consumer for the PostgreSQL `job` table. It runs only the kinds listed in a new `UBYHOST_GO_JOB_KINDS`, and the Python consumer stops claiming those kinds. The first Go-owned kind is `billing_snapshot`: one idempotent upsert per billing account into `billing_month_snapshot`, priced by a Go port of `billing.quote` that is checked against Python with committed fixtures. Rollback is removing the kind from `UBYHOST_GO_JOB_KINDS`.

## 4. Steps
1. `App/scripts/billing_fixtures.py` (same header style as `crypto_fixtures.py`, never reads `.env` or the database): writes JSON cases for `billing.quote` over apartments 0, 1, 4, 5, 9, 10, 23; both plans; both intervals; ttlock and whitelabel on and off; founder on and off; discounts 0, 1, 15, 50, 100; plus `_monthly` cases including half values (e.g. totals 6, 18, 30, 1194). Each case holds its inputs and the expected dict. Print `fixtures written: <n>`. Commit its output as `go/internal/billing/testdata/quote_fixtures.json`.
2. `App/tests/test_billing_fixtures.py`: regenerating into `tmp_path` equals the committed file byte for byte (copy the crypto test).
3. `go/internal/billing/quote.go`: constants and `Quote(apartments int, plan, interval string, ttlock, whitelabel, founder bool, discountPercent int) (Quote, error)` with the same errors for an unknown plan or interval and a discount outside 0-100, plus `Monthly(total int, interval string) int`. Test: every fixture case matches.
4. `go/internal/billing/snapshot.go`: `WriteMonthSnapshot(ctx, pool, month string, now string) (int, error)`: the same SELECT as `portfolio` (only the columns needed), then for each row the same `INSERT ... ON CONFLICT (owner_user_id, month) DO UPDATE` as Python, inside one transaction. `net = total + carry_czk`, `monthly = Monthly(net, interval)`, booleans stored as 0/1 like Python. Month is `YYYY-MM` of today in UTC.
5. `go/internal/jobs/queue.go`: `Claim(ctx, pool, kinds []string)` (Python's SQL plus `AND kind = ANY($n)`), `Finish`, `Fail` with Python's backoff and dead rules, and `Run(ctx, pool, kinds, handlers map[string]func(ctx) error, intervalMinutes map[string]int)` that drains up to 50 due jobs every 30 s until ctx is done. On success: resolve the alert (copy `alerts.resolve` SQL) and upsert `settings` `job_last_ok:<kind>`. On the dead transition: raise the alert as in section 2. Log one line per run: `job run job=<kind> ok=<0|1> ms=<n> rows=<n>`, no names or URLs.
6. `main.go`: read `UBYHOST_GO_JOB_KINDS` (comma list, trimmed). Unknown kind (anything but `billing_snapshot`) means exit 1 with a clear message. Empty means no consumer. Otherwise start `jobs.Run` in a goroutine that stops on shutdown before the pool closes.
7. Python: `config.GO_JOB_KINDS` from `UBYHOST_GO_JOB_KINDS` (same parsing as line 375). In `scheduler`, at the kinds check, refuse to start if `GO_JOB_KINDS` is not a subset of `JOB_QUEUE_KINDS` (the Python scheduler must still enqueue them). In `jobqueue.claim`, skip Go kinds: add `AND NOT (kind = ANY(?))` with `list(config.GO_JOB_KINDS)` only when the set is non-empty, so the SQL is unchanged otherwise.
8. Tests. Go (PostgreSQL from `UBYHOST_TEST_DATABASE_URL`, skip only when it is unset; CI sets it): create the `job`, `settings`, `alerts`, `billing_account`, `user_account`, `billing_month_snapshot` tables by applying `App/migrations_pg` the way `go/internal/schema/goose_test.go` does; then claim honours `kinds`, a failed job backs off 1 minute then dies after 5 attempts and raises one alert, success writes `job_last_ok:billing_snapshot`, and the snapshot of two accounts (one founder yearly, one max monthly with 15 % discount and carry) has the fixture prices. Python, in `test_job_queue.py` (PostgreSQL marker like the existing ones): a row of a Go kind is not claimed by Python, and a Go kind outside `JOB_QUEUE_KINDS` stops the scheduler.
9. Compose: add `UBYHOST_GO_JOB_KINDS: ${UBYHOST_GO_JOB_KINDS:-}` to `ubyhost-go` only. `docs/ENVIRONMENT.md`: one row after `UBYHOST_JOB_QUEUE_KINDS`: "Empty. PostgreSQL only. Kinds the Go service runs instead of Python; each must also be in `UBYHOST_JOB_QUEUE_KINDS`. Today only `billing_snapshot`."
