## 1. Objective

Orchestrator review of the fee screenshots (390, 1280 and 2000 px) found four layout faults:
1. On the `/stay-fees` phone cards, the row menu "⋮" sits alone on its own grid row, which leaves a large empty band in every card.
2. On `/stay-fees/<id>`, the message-text copy button wraps under the textarea, because `.copyrow` only lets inputs flex, not textareas.
3. Under "Your records", "Mark as sent" drops below its Message ID field while "Mark as paid" floats beside the field.
4. "Payment to the council" and "Guests in this period" have no space above them, because they are bare `<section>`s rather than `ui-section`.

Fix all four in `host2.css` plus two class additions in the template. Commit once. Never push.

## 2. Context

The fee list keeps its legacy `lc-fees` card grid (a `host.css` container query, see 0142 section 2); this brief only places the actions cell inside it. `host2.css` loads after `host.css`, so equal-specificity rules here win. S2 lint: no bare px in margin, padding, gap or font-size.
