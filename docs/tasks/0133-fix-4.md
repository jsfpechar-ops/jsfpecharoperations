## 1. Objective

The dashboard's phone overflow button passes `class="..."` inside `attrs` to `ui_icon_button`. The macro already writes its own `class`, so the button ends up with two `class` attributes. The browser keeps the first, so the button has no `ui-ph-menu` class and is hidden on phone as a quiet button. Phone hosts then cannot reach Add cleaning or Sync. `dev_ui.html` does the same thing. Add an `extra_class` parameter to the macro and use it. Then confirm the setup banner shows its "Finish setup" button.
